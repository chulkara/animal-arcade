# Moose 3D source files — local only

The user-supplied `Animated Animals 1.0.zip` includes a fully rigged moose model, body/head/antler PNGs and separate Cervid FBX animations. Original files and two labeled color variants are bundled into the user's **Moose Motion Lab V1** local review ZIP.

**No FBX, PNG or native animation binaries are committed here** while commercial/public redistribution rights remain unverified.

The active game plan is **Bear + Moose only**. Tiger V4 is paused and preserved; Lion is not in scope. Full playable roster integration is pending visual approval and licensing. The approved painted menu stays unchanged.

See `docs/moose-motion-intake.md`, `src/moose-assets-core.js`, `src/moose-action-core.js`, and `tests/moose-motion.test.mjs`.
